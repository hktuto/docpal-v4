# pdfSign

A mono solution to add and apply signatures into PDF files.

## Features

### 1. Frontend PDF Sign Designer
- Load PDF in a web page
- Add signature(s) into the document visually
- Save signature data to backend for PDF generation

### 2. Backend PDF Converter
- Load PDF and signature settings from frontend
- Generate a new PDF with applied signatures

## Usage

- Use the frontend designer to visually place signatures on a PDF.
- Submit the signature data to the backend.
- The backend generates a new PDF with the signatures applied.

## Structure

- `src/frontend/` - Frontend designer code
- `src/backend/` - Backend PDF processing code
